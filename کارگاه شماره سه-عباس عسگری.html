پراکسی‌ای که ابزار را از مدل جدا می‌کند

ابزارهای کدنویسی معمولاً به یک مدل مشخص وصل‌اند. FCC بین ابزار و مدل می‌نشیند، پروتکل‌ها را به هم ترجمه می‌کند و استریم، فراخوانی ابزار و حالت تفکر را حفظ می‌کند. طبق README این پروژه مستقل است و وابسته به Anthropic نیست.

چرا مهم است؟

  • هزینهٔ عامل‌های کدنویسی با جابه‌جایی آزاد بین مدل‌ها قابل کنترل می‌شود.
  • یک پنل واحد برای کلیدها، مدل‌ها و fallbackها دارد.
  • چهار خانوادهٔ پروتکل را می‌فهمد: Anthropic، OpenAI Chat، OpenAI Responses و Gemini.

برداشت کلی

  • کد لایه‌بندی‌شده است و آزمون‌ها حدود ۱٫۹ برابر کد تولیدی‌اند.
  • گستردگی پروژه هزینهٔ نگهداری دارد: ۲۶۵ ایشو و ۸۱ پول‌ریکوئست باز.
  • ریسک‌های اصلی غیرفنی‌اند: شرایط استفادهٔ ارائه‌دهندگان، سهمیهٔ رایگان و مجوز AGPL.
روش: آمار ستاره و ایشو از صفحهٔ GitHub آمده و شمارش فایل و خط از کلون سطحی آخرین کامیت است. کد اجرا نشده است. عددهایی مثل «۱٫۳ میلیارد توکن رایگان در ماه» و «تا ۹۰٪ صرفه‌جویی توکن» ادعای README هستند و راستی‌آزمایی نشده‌اند.

کد کجا زندگی می‌کند؟

پکیج اصلی حدود ۴۳۴ فایل پایتون و ۸۰٬۶۰۰ خط دارد. بیشترین حجم مال آداپتورهای ارائه‌دهندگان است، چون هر کدام ناسازگاری‌های خودش را دارد.

آنچه کاربر می‌بیند

پیکربندی از پنل مرورگر یا متغیرهای محیطی انجام می‌شود.

مسیریابی بر اساس لایه

هر لایهٔ Claude Code مدل جدا می‌گیرد: MODEL MODEL_OPUS MODEL_SONNET MODEL_HAIKU MODEL_FABLE. هر مدل فهرست fallback با سطح استدلال و شمارهٔ کلید مخصوص خودش دارد.

پنل Admin

  • ثبت کلید و تست اتصال
  • ورود OAuth برای ChatGPT و GitHub Copilot
  • کشف خودکار LM Studio، llama.cpp و Ollama

دسترسی از هرجا

  • ترمینال، اپ‌های دسکتاپ و IDE
  • گوشی از طریق Discord و Telegram (/stats /stop /clear)
  • رابط نشست در مرورگر

پایداری

  • تلاش مجدد، محدودیت نرخ و هم‌زمانی
  • fallback بین مدل، ارائه‌دهنده و چند کلید
  • کاهش توکن با RTK و Headroom (ادعای README)

این موارد از خواندن کد و تنظیمات CI به دست آمده‌اند.

کیفیت کد

  • ruff برای قالب و لینت، ty برای نوع
  • CI دستورهای # type: ignore را رد می‌کند
  • نسخهٔ پایتون روی ==3.14.10 قفل است
  • تست‌های قرارداد مرز ماژول‌ها را نگه می‌دارند

انتشار

  • عنوان PR باید با patch: یا minor: یا major: شروع شود
  • نسخه بعد از merge خودکار محاسبه و منتشر می‌شود
  • آزمون روی سه سیستم‌عامل به‌علاوهٔ Playwright
  • اکشن‌های CI با هش کامیت پین شده‌اند

  • Admin فقط محلی است: api/admin_security.py هاست و Origin را بررسی می‌کند و فقط loopback را می‌پذیرد.
  • احراز هویت اختیاری پراکسی برای هر خانوادهٔ پروتکل وجود دارد.
  • اعتبارسنجی سخت‌گیر: درخواست Gemini با فیلد JSON تکراری رد می‌شود.
  • پیش‌فرض سرور 127.0.0.1 است. اگر آن را روی شبکه باز کنید، احراز هویت را فعال کنید.

جمع‌بندی

FCC بالغ‌تر از یک اسکریپت پراکسی ساده است: معماری چندلایه، ترجمهٔ چندپروتکلی، آزمون‌های گسترده و نصب و به‌روزرسانی خودکار دارد. برای اجرای عامل‌های کدنویسی با مدل‌های دلخواه یا محلی گزینهٔ قدرتمندی است. ارزش واقعی آن به پایداری سهمیه‌ها و رعایت شرایط استفادهٔ ارائه‌دهندگان بستگی دارد، نه فقط به کیفیت کد.

از نصب تا اجرا

مراحل طبق README. مدل پیش‌فرض نمونه nvidia_nim/nvidia/nemotron-3-ultra-550b-a55b است.

# 1. نصب با اسکریپت README (macOS / Linux)
$ sh install.sh

# 2. اجرای سرور (لینوکس)
$ fcc-server

# 3. کلید NVIDIA NIM را در Admin UI وارد کنید
# 4. اجرای ابزار دلخواه
$ fcc-claude

# عیب‌یابی
$ fcc-doctor
